# 바카라산악회 하이로우 토너먼트

24인 실시간 하이로우 토너먼트입니다. Node.js, Express, Socket.IO로 동작합니다.

## 관리자 기능

- 게임 시작: 착석자는 유지하고 첫 라운드를 시작합니다.
- 게임 재시작: 좌석은 유지하며 전원 보유금, 카드, 라운드, 랭킹을 초기화합니다.
- 게임 종료(방폭): 모든 참가자와 좌석, 게임 상태를 제거합니다.
- 게임 시작과 동시에 참가가 마감되어 관전자는 중간 착석할 수 없습니다.
- 참가자가 한 번 선택한 좌석은 방폭 전까지 변경할 수 없으며, 재접속하면 같은 좌석으로 복귀합니다.

## 연승 누적 및 인출

- 첫 적중 이후 배당은 다음 적중 배당과 곱하기로 누적됩니다.
- 연승이 진행되는 동안 최초 베팅금은 고정되며 칩 추가나 금액 변경은 할 수 없습니다.
- `인출`을 누르면 최초 베팅 원금에 누적배당을 곱한 금액이 보유금으로 지급됩니다.
- 연승 도전 중 실패하면 진행 중이던 원금과 누적 당첨금이 모두 소멸합니다.
- 적중 후 다음 10초 동안 방향 선택이나 인출을 하지 않으면 자동 인출됩니다.
- LOW/HIGH에서 같은 숫자가 나오면 적특으로 누적 상태를 유지합니다.

## Render 배포

1. 이 저장소로 새 Web Service를 생성합니다.
2. Blueprint를 사용하면 `render.yaml`이 자동 적용됩니다.
3. 환경변수 `ADMIN_PASSWORD`에 방장 비밀번호를 입력합니다.
4. Build Command는 `npm install`, Start Command는 `npm start`입니다.

서버 상태 확인: `/health`
